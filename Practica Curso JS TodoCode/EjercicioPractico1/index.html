Ejercicio practico 1

  • Ingresar dos numeros mediante prompt y almacenar sus valores en dos variables distintas
  • Realizar una resta entre los dos valores en JS
  • Almacenar el resultado en una variable
  • Importar el archivo JS desde una pagina HTML
  • Si el resultado de la resta es mayor a 0, mostrar mediante un concole.log() el mensaje "Es mayor a 0"
  • Si es mayor a 0, comprar si el numero es par, en caso de quelo sea mostrar como mensaje "Es par" en caso de no "Es impar"
  • En caso de que sea menor a 0, mostrar un mensaje que diga "Es menor o igual a 0"
