Proyecto Integrador JavaScript "Lista de Tareas"
Consigna:
1) Crear una lista de tareas (to-do list) en HTML que incluya un cmapo de tecto de entrada y un boton de "Agregar tarea".
2) Cuando el usuario introduzca una tarea y presine en el boton, esta debera añadirse a una lista de tareas que en un principio debera estar vacia.
3) Cada tarea en la lista debera estar acompañada por un boton "Eliminar"
4) Al hacer click en dicho boton la tarea correspondiente debera ser eliminada.
